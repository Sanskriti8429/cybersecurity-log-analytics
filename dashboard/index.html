🔧 How This Works

The real pipeline behind this dashboard
An attack happens → Kafka receives the raw log event → Spark reads it continuously, detects the pattern, and writes an alert to MongoDB → this dashboard reads MongoDB. Separately, the same kind of logs are stored permanently in Hadoop (HDFS) and used to train a machine learning model in Spark MLlib.

What Spark is doing
  • Spark Structured Streaming — reads Kafka continuously, checks every 60-second window for 10+ failed logins from one IP, writes matches to MongoDB within seconds
  • Spark Batch — loaded 2.83 million rows of the CICIDS2017 intrusion-detection dataset into HDFS as cleaned Parquet
  • Spark MLlib — trained a Random Forest classifier on that data to recognize 13 attack types

📋 Detection Rules

The exact logic Spark uses to decide something is an attack
Rule A — Fast brute force
10+ failed logins from one IP within 60 seconds
Catches the most common attack: a script rapidly trying passwords. This rule currently feeds this dashboard.
Rule B — Slow brute force
20+ failed logins from one IP within 10 minutes
Catches attackers who deliberately slow down to avoid Rule A.
Rule C — Distributed / credential stuffing
20+ failures on one account from 5+ IPs within 60 seconds
Catches botnets trying the same stolen password across many machines at once.
Port scan rule
15+ distinct ports touched by one IP within a time window
Flags reconnaissance before a real attack.
Why three rules instead of one?

Testing on harder synthetic attack data showed a single rule (Rule A alone) caught classic brute force almost perfectly, but completely missed slow and distributed attacks (0 of 301 such events). Adding Rules B and C raised recall from 66.5% to 95.3%, at a small cost in false positives (11 → 20 out of thousands of normal events).

💡 Why macro F1 matters more than accuracy: accuracy looks great (98.5%) even when the model completely misses rare attacks, since normal traffic is 80% of the data. Macro F1 treats every attack type equally — class weighting improved it by 10 points, catching rare attacks the baseline missed.
